# STM32F107-JW-ROBOT  
**基于 STM32F107 的智能巡检机器人**

本项目实现了面向工业设备的自动巡检功能原型，通过超声波测距与温度传感完成定点数据采集，支持手动/自动模式切换及障碍物避停。目前基础功能已稳定运行，**巡检点定位精度正在优化中**。

## ✅ 已实现功能
- **自动巡检**：按预设距离（如 300mm/400mm/500mm）自动停靠并记录温度数据  
- **安全保护**：超声波实时检测障碍物，触发紧急停机  
- **人机交互**：OLED 显示状态 + 串口指令控制（MENU/DATA/CTRL 界面）  
- **故障上报**：GPIO 限位开关检测 + 异常状态 LED 指示  
- **模块化设计**：电机控制、传感器驱动、通信逻辑解耦，便于功能扩展  

## 🔧 开发环境
- **主控芯片**：STM32F107VCT6（ARM Cortex-M3）  
- **开发工具**：Keil MDK v5.06 + VS Code（代码编辑）  
- **编程语言**：C（标准库 + 寄存器级外设配置）  

## 🚧 后续优化方向
- 提高巡检点定位精度（优化减速曲线 + 超声波滤波）  
- 增加多轮次巡检数据存储与回传  
- 支持路径规划与多点连续巡检
