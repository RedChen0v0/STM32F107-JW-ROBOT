# Project422 智能避障机器人用户手册

## 一、产品简介

Project422 智能避障机器人是一款基于 STM32F10x 微控制器开发的教学级智能系统。该系统集成了电机驱动、485总线传感器（超声波测距 + 温度采集）、OLED显示等人机交互功能，适用于智能教学实践和项目开发。

---

## 二、快速开始

### 2.1 硬件连接

请按照以下步骤连接各模块：

1. **主控板**：连接 STM32F10x 开发板
2. **电机**：接到电机驱动输出（注意正负极）
3. **限位开关**：
   - 限位开关1 → GPIO_C14
   - 限位开关2 → GPIO_C13
4. **485传感器**：
   - 超声波传感器 → USART1 (TX/RX)
   - 温度传感器 → USART1 (与超声波共用)
5. **OLED屏幕**：连接到I2C或SPI接口
6. **串口调试**：USART3 连接电脑（用于接收控制指令）

### 2.2 软件烧录

1. 使用 ST-Link 或 J-Link 仿真器连接开发板
2. 打开 Keil MDK 或其他 IDE
3. 编译项目并下载到 STM32F10x
4. 复位开发板，系统自动启动

### 2.3 验证运行

系统上电后会自动：
1. 初始化各模块（GPIO、串口、OLED、电机）
2. OLED 显示初始化过程：`system init` → `running` → `success`
3. 显示青鸟 LOGO
4. 启动电机，LED 指示灯开始闪烁

## 三、功能使用

### 3.1 电机控制

#### 自动运行
- 系统上电后电机自动启动
- 初始方向由限位开关状态决定
- 运行中遇障碍物（距离 ≤ 48mm）自动停车

#### 手动控制
通过串口发送指令控制（USART3，波特率 115200）：

| 指令 | 功能 | 说明 |
|------|------|------|
| `DATA` | 切换到数据显示界面 | 显示距离和温度 |
| `LOGO` | 切换到LOGO显示界面 | 显示青鸟LOGO |

### 3.2 传感器数据查看

1. 通过串口发送 `DATA` 指令
2. OLED 屏幕显示：
   - 第1行：距离（单位：mm）
   - 第2行：温度（单位：℃）

### 3.3 状态指示

- **LED1 (GPIO_E3)**：每10个主循环周期闪烁一次
- **LED2 (GPIO_E4)**：与 LED1 配合显示运行状态

## 四、参数配置

### 4.1 避障距离阈值

在 `app_func.c` 中找到以下变量进行修改：

```c
uint8_t stopThre = 48;  // 超声波检测停止距离阈值，单位：cm
```

### 4.2 串口参数

| 参数 | 值 |
|------|-----|
| USART1 波特率 | 9600 |
| USART3 波特率 | 115200 |
| 数据位 | 8位 |
| 停止位 | 1位 |
| 校验位 | 无 |

### 4.3 485传感器寄存器

| 传感器 | 寄存器地址 | 功能 |
|--------|------------|------|
| 超声波 | 0x0101 | 测距数据 |
| 温度 | 0x0200 | 温度数据 |

## 五、故障排除

### 5.1 常见问题

| 现象 | 可能原因 | 解决方法 |
|------|----------|----------|
| OLED 无显示 | I2C/SPI 连接问题 | 检查接线是否正确 |
| 电机不转 | 电机驱动故障 | 检查电源和驱动连接 |
| 传感器无数据 | 485总线接线错误 | 检查 TX/RX 是否接反 |
| 串口指令无效 | 波特率不匹配 | 确认串口调试助手波特率为115200 |

### 5.2 调试方法

1. **查看串口输出**：系统启动时会打印 `system init completed`
2. **LED 指示**：LED 正常闪烁说明主循环在运行
3. **逐步调试**：注释掉部分代码定位问题

## 六、安全注意事项

1. **电机运行期间请勿用手触碰运动部件**
2. **首次运行前检查限位开关是否正常**
3. **485传感器需要正确接地，否则可能导致通信失败**
4. **请使用 5V~12V 直流电源供电（根据电机规格选择）**
5. **禁止在主板通电情况下插拔传感器**
