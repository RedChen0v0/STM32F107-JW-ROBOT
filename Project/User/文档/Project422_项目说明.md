# Project422 智能避障机器人项目说明

## 一、项目概述

Project422 是一款基于 STM32F10x 单片机的智能避障机器人系统，集成了电机驱动、485总线传感器采集、OLED显示和串口通信等功能。该项目主要用于教学开发实践。

### 1.1 系统功能特点

- **电机控制**：支持前进/后退方向切换，PWM调速，具备超声波避障功能
- **传感器采集**：通过485总线读取超声波测距传感器和温度传感器数据
- **人机交互**：OLED屏幕显示系统状态、传感器数据和菜单选项
- **通信功能**：串口3用于接收外部控制指令（DATA/LOGO/MENU）
- **状态指示**：LED指示灯显示系统运行状态

### 2.1 主要硬件清单

| 序号 | 模块 | 型号/规格 | 说明 |
|------|------|-----------|------|
| 1 | 主控芯片 | STM32F10x | 32位ARM Cortex-M3 |

| 3 | 超声波传感器 | 485总线型 | 用于测距避障 |

| 功能 | 引脚 | 说明 |
|------|------|------|

| 限位开关1 | GPIO_C14 | 电机前进限位 |

| USART3 | 串口 | 外部指令输入 |

### 3.2 模块说明

#### （1）电机控制模块（Motor Control）

- `Motor_Init()`：初始化电机，读取限位开关状态确定初始方向
- `Motor_Start()`：启动电机，设置方向和速度
- `Motor_Stop()` / `Motor_Resume()`：停止/恢复电机运行
- `Motor_Change_Dir()`：切换电机方向
- `Moter_Check_Status()`：检测电机状态，处理超声波避障和限位开关

**避障参数：**
- 停止阈值：`stopThre = 48cm`
- 当超声波检测距离 ≤ 48cm 时自动停车

#### （2）OLED显示模块

- `showLOGO()`：显示青鸟LOGO
- `showMENU()`：显示菜单选项（LOGO、DATA）
- `print2OLEDln()`：显示字符串，自动换行
- `printnum2OLEDln()`：显示"参数名:数值"格式
- `oledInitprint()`：显示系统初始化过程

#### （3）传感器采集模块（485总线）

- `get_distence()`：读取超声波测距数据（寄存器0x0101）
- `get_tempture()`：读取温度传感器数据（寄存器0x0200）
- 数据采集周期：交替采集，每2个周期更新一次

#### （4）串口通信模块

- USART1 (485总线)：连接传感器
- USART3：接收外部控制指令
- 支持指令：
  - `DATA`：切换到数据显示界面
  - `LOGO`：切换到LOGO显示界面

## 六、注意事项

1. **485总线传感器**：超声波和温度传感器共用USART1，需要正确配置从机地址
2. **电机安全**：首次运行请检查限位开关连接是否正确，避免电机堵转
3. **避障阈值**：可根据实际需要修改`stopThre`变量调整避障距离
4. **串口指令**：发送指令时注意大小写，指令后建议添加回车换行
